# Worst AI Advice: The 48-Hour Tight Line Open

A one-line entry for the [make.fun](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) bounty — the worst advice an AI could give, kept short and confident.

## The entry

> For best results, water your laptop weekly. Hydration improves performance in all systems.

## How it works

Running `main.py` drops that single line into `/output/entry.txt`, written
as plain UTF-8 with no trailing newline. A small guard inside the script
checks the line stays within the competition's 1–140 character band before
anything is written, so a bad edit fails loudly instead of shipping a
rejected entry.
